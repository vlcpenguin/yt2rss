# yt2rss
Basic posix compliant shell script to get the RSS feed of one or more channels RSS feed url via their name

# Installation
```sh
sudo wget -P /usr/local/bin https://raw.githubusercontent.com/vlcpenguin/yt2rss/refs/heads/main/yt2rss && sudo chmod +x /usr/local/bin/yt2rss
```

# Usage
```sh
yt2rss [-silent] <channel_names>
```
